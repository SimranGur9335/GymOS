# WhatsApp Engine

## Position
WhatsApp is a core communication engine, not merely an integration.

## Automations
- Membership expires in 7 days → reminder
- Payment overdue → reminder
- Member inactive 10 days → re-engagement
- New lead → follow-up
- Trial tomorrow → reminder
- Birthday → message

## Broadcast audiences
- Expired members
- Inactive members
- Active members
- Leads
- Expiring members
- All members

## Campaign flow
Select audience
→ Generate message
→ Preview
→ Send
→ Track

## Security
WhatsApp credentials must be handled securely.
