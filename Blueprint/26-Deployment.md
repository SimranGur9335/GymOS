# Deployment

## Frontend
Vercel.

## Backend
Railway / Render / equivalent cloud backend.

## Database
Supabase PostgreSQL.

## Storage
Supabase Storage.

## Authentication
Supabase Auth.

## Deployment principle
Do not force the entire FastAPI backend into a serverless architecture if it creates unnecessary cold-start issues.

## Environment/security
Secrets and API keys must not be committed to source control.
