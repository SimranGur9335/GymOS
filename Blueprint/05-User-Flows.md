# User Flows

## Gym Business entry
Landing Page
→ Go to Gym Portal
→ Select Your Gym
→ Gym Login
→ Role Detection
→ Owner / Trainer / Member

## Discover flow
Find Gym
→ Search / Filters
→ Gym Profile
→ Compare or Enquire
→ Enquiry enters GymOS Leads

## Owner daily flow
Login
→ Dashboard
→ Action Center
→ Resolve pending payments / expiring memberships / inactive members / lead follow-ups
→ Take action
→ Measure result

## Membership flow
Create plan
→ Assign to member
→ Track active/expiring/expired/suspended/cancelled
→ Renewal action

## Payment flow
Payment recorded
→ Paid/Pending/Partial/Overdue/Refund
→ Receipt/payment link
→ Revenue tracking
→ Reminder where required

## Retention flow
Attendance data
→ Rule detection
→ At-risk alert
→ WhatsApp action
→ Member returns
→ Retention outcome
