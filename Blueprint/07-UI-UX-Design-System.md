# UI / UX Design System

## Product direction
The public site should feel like a premium SaaS product, not a basic gym website.

## Dashboard principle
Do not build dashboards as collections of charts. Prioritize:
1. What needs attention?
2. Why does it matter?
3. What action can be taken?
4. What was the outcome?

## Signature component: Action Center
Examples:
- Pending payments → Recover Payments
- Expiring memberships → Send Renewals
- Inactive members → Start Win-back
- Leads needing follow-up → View Leads

## Public Gym profile
Should clearly expose:
- Location
- Rating
- Price
- Amenities
- Photos
- Videos
- Timings
- Offers
- Contact
- Directions
- Compare
- Enquire

## Member experience
Member portal can be a PWA/web experience. WhatsApp remains the primary communication channel.

## Design decisions not specified in source
Exact color tokens, typography, spacing scale, component library implementation and responsive breakpoints must be defined during UI implementation.
