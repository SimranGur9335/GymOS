# Gym Discovery Web Data

## Data sources
Gym discovery information can come from:
- Appropriate public web/business sources
- Owner-provided information

## Data types
- Rates/pricing
- Images
- Videos
- Location
- Amenities
- Reviews/ratings
- Timings
- Offers

## Freshness
Publicly sourced prices should show:
- Source
- Last checked date

They must not be presented as guaranteed current prices.

## Video handling
Prefer embedding/linking original public videos rather than downloading/re-hosting copyrighted content.

## Trust model
Owner-verified information and public-source information should be distinguishable in the product.
